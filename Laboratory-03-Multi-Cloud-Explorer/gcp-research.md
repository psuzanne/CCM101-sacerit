## Brief Overview

Google Cloud is a cloud computing platform provided by Google. It provides cloud services for computing, storage, networking, databases, data analytics, artificial intelligence, machine learning, and application development. Google Cloud services run on infrastructure that Google also uses for products such as Google Search, Gmail, and YouTube.

## Global Infrastructure

Google Cloud organizes its physical infrastructure into regions and zones. As of June 30, 2026, Google Cloud lists **43 regions and 130 zones**, with infrastructure available across more than 200 countries and territories.

Regions are geographic locations, while zones are isolated locations within regions. Using multiple zones can provide redundancy and help improve application availability. Google Cloud also provides a global network and edge locations to support applications and users around the world.

## Cloud Management Console

The **Google Cloud console** is a web-based interface used to create, manage, monitor, and configure Google Cloud resources and services. Google Cloud organizes resources using projects, which contain the settings, permissions, and other information for applications and workloads.

## Four Core Services

1. **Compute Engine** – Provides flexible virtual machines for running workloads on Google's infrastructure.
2. **Cloud Storage** – Provides scalable object storage for storing and accessing data.
3. **Google Kubernetes Engine (GKE)** – Provides a managed Kubernetes service for deploying and managing containerized applications.
4. **Cloud IAM** – Controls access to Google Cloud resources by assigning roles and permissions to users and other identities.

## Three Advantages

1. **Strong AI and data capabilities** – Google Cloud provides services and infrastructure for artificial intelligence, machine learning, and large-scale data processing.
2. **Global network and infrastructure** – Google Cloud provides infrastructure across many regions and zones and supports global connectivity.
3. **Kubernetes support** – Google Cloud provides Google Kubernetes Engine, a managed Kubernetes service that can be used to deploy and manage containerized applications.

## Typical Enterprise Use Cases

Enterprises can use Google Cloud for application hosting, data storage, big data analytics, artificial intelligence and machine learning, containerized applications, databases, and global web applications. Google Cloud is also useful for organizations that need scalable computing and data-processing resources.
