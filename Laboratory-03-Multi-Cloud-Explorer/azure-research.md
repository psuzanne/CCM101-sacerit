## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform for building, deploying, and managing applications and services. Azure provides services for computing, storage, networking, analytics, artificial intelligence, and other cloud requirements. Microsoft states that Azure offers more than 200 products and services through its global network of datacenters.

## Global Infrastructure

Azure has a global network of datacenters organized into regions and availability zones. Microsoft currently lists **70+ announced Azure regions**. Availability Zones are physically and logically separated datacenters with independent power, networking, and cooling. They are connected through low-latency networks to support highly available applications.

Azure's global infrastructure allows organizations to select regions based on factors such as application location, performance, availability, and regulatory requirements.

## Cloud Management Console

The **Azure portal** is a web-based unified console for creating and managing Azure resources. Users can use the portal to create resources, manage subscriptions, monitor applications and services, configure virtual machines, manage databases, and review costs.

## Four Core Services

1. **Azure Virtual Machines** – Provides virtual machines for running applications and workloads in the cloud.
2. **Azure Blob Storage** – Provides object storage for large amounts of unstructured data.
3. **Azure Virtual Network** – Provides networking capabilities for Azure resources and applications.
4. **Microsoft Entra ID** – Provides identity and access management for users and resources.

## Three Advantages

1. **Strong Microsoft integration** – Azure works well with Microsoft's technologies and services, making it useful for organizations already using Microsoft products.
2. **Global availability** – Azure has a large global infrastructure with many announced regions, allowing organizations to deploy services in different geographic locations.
3. **Security and resiliency** – Azure provides built-in security features and availability options such as Availability Zones to help organizations protect applications and maintain availability.

## Typical Enterprise Use Cases

Enterprises commonly use Azure for hosting Windows-based applications, cloud migration, databases, networking, data analytics, artificial intelligence, application development, backup, and disaster recovery. Azure is especially useful for organizations that already depend on Microsoft technologies because of its integration with the Microsoft ecosystem.
