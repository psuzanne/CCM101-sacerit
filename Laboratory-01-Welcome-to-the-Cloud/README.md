## Mission Overview

This laboratory activity introduces the basic tasks involved in working with a cloud-based Linux environment. It focuses on using the KillerCoda Playground, exploring the Linux operating system, gathering system information, organizing files and directories, and creating a Cloud Computing Portfolio using GitHub.

## Objectives

The objectives of this laboratory activity are to access and use a cloud-based Linux environment through KillerCoda, explore and navigate the Linux operating system, gather basic system information, organize files and directories using Linux commands, create and maintain a GitHub repository, and document technical work using Markdown.

## Activities Performed

During this laboratory activity, I accessed the KillerCoda Playground and used an Ubuntu Linux environment. I explored the terminal and verified that it was functioning properly. I created a new Linux user account with a home directory, Bash, and sudo access and logged in to the new account. I also checked and recorded the current username, working directory, and hostname.

I then investigated the Linux environment by checking the Linux distribution, kernel version, CPU information, total memory, and available disk space. I recorded these findings in a Markdown file named "system-information.md". I also created the required folder structure and the "about-me.md" file inside the Notes folder.

After completing the Linux activities, I created a public GitHub repository for my Cloud Computing Portfolio. I organized the required files and folders in the repository and prepared screenshots as evidence of the completed activities.

## Linux Commands Used

The following Linux commands were used during the laboratory activity:

- "pwd" – displays the current working directory.
- "whoami" – displays the current username.
- "hostname" – displays the hostname of the system.
- "cat /etc/os-release" – displays information about the Linux distribution.
- "uname -r" – displays the kernel version.
- "lscpu" – displays CPU information.
- "free -h" – displays memory information.
- "df -h" – displays available disk space.
