## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It was launched in 2006 and provides many cloud services that organizations can use to build, deploy, store, and manage applications and data. AWS supports startups, enterprises, government organizations, and other types of customers.

## Global Infrastructure

AWS has a global infrastructure made up of geographic **Regions** and **Availability Zones (AZs)**. An AWS Region is a separate geographic area, while Availability Zones are isolated locations within a Region. AWS currently lists **39 geographic Regions and 123 Availability Zones**, with additional infrastructure announced for the future.

The use of multiple Availability Zones helps organizations design applications that are more highly available and fault tolerant. AWS also provides other infrastructure locations such as Local Zones and Wavelength Zones for specific workloads and low-latency requirements.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS services and resources. Through the console, users can create and configure cloud resources, monitor services, and manage their AWS environment.

## Four Core Services

1. **Amazon EC2 (Elastic Compute Cloud)** – Provides virtual servers that can be used to run applications and workloads.
2. **Amazon S3 (Simple Storage Service)** – Provides object storage for storing and retrieving data.
3. **Amazon VPC (Virtual Private Cloud)** – Allows users to create and manage networking environments for their AWS resources.
4. **AWS IAM (Identity and Access Management)** – Controls access to AWS resources by managing users, roles, and permissions.

## Three Advantages

1. **Wide range of services** – AWS provides a broad selection of cloud and AI capabilities that can support different types of applications and organizations.
2. **Global infrastructure** – AWS provides infrastructure in many geographic locations, allowing organizations to deploy applications closer to their users.
3. **Scalability and flexibility** – Organizations can increase or decrease cloud resources depending on their workload and business requirements.

## Typical Enterprise Use Cases

AWS can be used by enterprises for application hosting, data storage and backup, website and mobile application development, databases, data analytics, artificial intelligence and machine learning, and disaster recovery. Its global infrastructure also makes it suitable for organizations that need applications available to users in different parts of the world.
