# Client A – Startup Company

**Recommended Cloud Platform: AWS**

AWS is a good choice for the startup because it provides services that can help a company launch an application and scale as it grows. AWS specifically provides services such as Amazon S3, Amazon EC2, and Amazon Amplify for startups, including mobile and web application development. AWS also provides flexible computing capacity, so the startup can adjust its resources as demand increases.

**Services the client could use:**

**1. Amazon Amplify** – for developing and deploying the mobile application's frontend and backend features.

**2. Amazon EC2** – for running application servers.

**3. Amazon S3** – for storing application files, images, and other data.

## Client B – University

**Recommended Cloud Platform: Microsoft Azure**

Microsoft Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's technologies, making the transition to cloud services more suitable for the university's existing environment. Azure Migrate can also help discover, assess, and migrate existing servers and applications to Azure.

**Services the client could use:**

**1. Azure Virtual Machines** – for running Windows Server workloads in the cloud.

**2. Microsoft Entra ID** – for identity and access management.

**3. Azure Migrate** – for assessing and migrating existing servers and applications.

## Client C – AI Research Company

**Recommended Cloud Platform: Google Cloud Platform (GCP)**

GCP is a strong choice for the AI research company because Google Cloud provides infrastructure designed for AI and machine learning workloads. Google Kubernetes Engine (GKE) can run AI/ML applications using scalable and managed Kubernetes infrastructure. GKE also supports GPU and TPU accelerators, which can be used for resource-intensive machine learning and data-processing workloads.

**Services the client could use:**

**1. Google Kubernetes Engine (GKE)** – for deploying and managing containerized AI/ML applications.

**2. Compute Engine** – for high-performance virtual machines and computing workloads.

**3. Cloud Storage** – for storing datasets, models, and other research files.

## Client D – Global E-Commerce Company

**Recommended Cloud Platform: AWS**

AWS is a suitable choice for the global e-commerce company because its infrastructure uses Regions and multiple Availability Zones, which can help applications remain available when individual locations experience problems. Amazon EC2 Auto Scaling can automatically adjust the number of compute instances based on demand, while Elastic Load Balancing can distribute traffic across application servers. This combination can help the company handle changing customer traffic while maintaining a highly available application.

**Services the client could use:**

**1. Amazon EC2** – for running the e-commerce application.

**2. Amazon EC2 Auto Scaling** – for automatically increasing or decreasing compute capacity.

**3. Elastic Load Balancing (ELB)** – for distributing incoming traffic across servers.
